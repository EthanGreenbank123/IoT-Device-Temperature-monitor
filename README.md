# IoT-outdoor-venue-temp-monitor-
An Internet of Things device that records temperature readings of a certain environment and sends the results to a cloud platform
# features 
real-time temp monitoring
edge ai classifiction (cold, moderate and hot) 
M2M communication which is ethernet based 
thingspeak allows cloud data storage and visualisation 
# Hardware used 
Arduino UNO 
ethernet shield 
ethernet cable 
DHT11 temp monitor 
jump wires 
router 
# software used 
arduino IDE 
SPI Library 
Ethernet Library 
DHT sensor library 
# cloud
